# lspcontact

Connect page LSPza. Single-page static site with embedded background and contact functionality.

## About

LSPContact is a minimal, single-page static site serving as the primary contact and connection hub for LSP (Local & Optimised).

### Design

- **Layout:** Single page, desktop-friendly, mobile-responsive
- **Background:** Embedded, full-screen
- **Contact Tab:** Prominent contact form/call-to-action
- **Fonts:** Unica One, Raleway, Crimson Text
- **Palette:** Gold, Cyan, Red (dark cards)

### Features

- Contact form
- Social links
- Quick response setup
- Set-and-forget deployment
